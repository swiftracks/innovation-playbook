## Value Propositions

### Primary Value Proposition

```
For [ICP Role] who [has this pain], [Product] is a [category] 
that [key benefit]. Unlike [alternative], we [unique differentiator].

Example:
For Engineering Managers who waste time in retrospectives, RetroAI 
is an AI-powered retrospective tool that delivers actionable insights 
in 30 minutes. Unlike manual analysis, we automatically identify 
patterns and generate clear action items.
```

```

### Consideration (Interest)

```

# 08 — Synthesize Insights

**Purpose**: Synthesize insights across all experiments and feedback

**Outcome**: Have synthesized insights from Outbound, Growth Marketing, and Product experiments documented in Swift CNS Insights, with patterns recognized and decisions informed by data

**Audience**: PM / Dev / Both

**Time**: Ongoing (continuous synthesis)

**Prerequisites**: [07 — Run Experiments](07-run-experiments.md) - Experiments running

## Learning Outcomes

By the end of this chapter, you will be able to:
1. Collect feedback from all channels (in-app, email, interviews, surveys, support)
2. Synthesize insights across Outbound, Growth Marketing, and Product experiments
3. Use Swift CNS Insights to aggregate learnings
4. Recognize patterns (ICP signals, channel effectiveness, product resonance)
5. Apply decision framework (what's working, what to pivot)
6. Close feedback loop with users

## Jobs-to-Be-Done

- **When**: I have experiments running and feedback coming in
- **I want**: To synthesize insights across all experiments and feedback
- **So that**: I can make data-driven decisions about what's working and what to pivot

## Inputs

- Experiments running from [07 — Run Experiments](07-run-experiments.md)
- Feedback from all channels
- Analytics data from tool stack
- Swift CNS account with experiments and Learning Cards

### 2. Synthesize Insights Across Experiments

**Synthesize Outbound Insights**:

**What to Synthesize**:
- Which ICP segments work?
- Which messaging resonates?
- Which channels convert?
- Which entry personas work?
- What patterns emerge?

**Synthesis Process**:
1. Review all Outbound experiments
2. Identify patterns across experiments
3. Document insights in Swift CNS
4. Create Learning Cards for key insights

**Synthesize Growth Marketing Insights**:

- What messaging performs?
- What patterns emerge?

**Synthesis Process**:

### 3. Use Swift CNS Insights to Aggregate

**Swift CNS Insights Overview**:

**Access Insights**:
1. Navigate to Insights tab in Swift CNS
2. View aggregated insights from all Learning Cards
3. Filter by category (Outbound, Growth Marketing, Product)
4. Filter by status (validated, invalidated, inconclusive)
5. View patterns across insights

**What You'll See**:
- Aggregated insights from all Learning Cards
- Insights organized by topic
- Status: validated or invalidated
- Tags and categories
- Links to source Learning Cards

**Insights Summary**:
- Total number of insights
- Number of validated insights
- Number of invalidated insights
- Number of unique tags
- Number of Learning Cards

**Pattern Recognition**:
- Patterns across multiple insights
- Contradictions or confirmations
- Strong signals vs. weak signals
- Surprises or unexpected findings

**Document in Swift CNS**:
- Review Swift CNS Insights regularly
- Document pattern recognition
- Create synthesis documents

### 4. Recognize Patterns

**Pattern Recognition Framework**:

**ICP Signals**:
- What ICP segments consistently work?
- What ICP segments consistently fail?
- What patterns emerge across Outbound, Growth, and Product?
- Example: Engineering Managers at 50-200 employee companies show consistent success across all categories

**Channel Effectiveness**:
- What channels consistently convert?
- What channels consistently fail?
- What patterns emerge across experiments?
- Example: LinkedIn consistently outperforms other channels

**Product Resonance**:
- What features consistently drive engagement?
- What UX improvements consistently help?
- What patterns emerge across experiments?
- Example: Onboarding optimization consistently improves first-time success

**Messaging Effectiveness**:
- What messaging consistently resonates?
- What messaging consistently fails?
- What patterns emerge across channels?
- Example: "Turn retrospectives into action" consistently performs best

**Cross-Category Patterns**:
- What works across Outbound, Growth, and Product?
- What fails across categories?
- What patterns inform strategy?
- Example: Engineering Managers at 50-200 employee companies + LinkedIn + optimized onboarding = validated path

**Document in Swift CNS**:
- Create pattern recognition document
- Document patterns by category
- Document cross-category patterns

### 5. Apply Decision Framework

**Decision Framework**:

**What's Working**:
- What experiments show success?
- What patterns validate?
- What should you scale?
- What should you double down on?

**What's Not Working**:
- What experiments show failure?
- What patterns invalidate?
- What should you stop?
- What should you pivot?

**What to Pivot**:
- What needs to change?
- What new directions to explore?
- What experiments to run?
- What hypotheses to test?

**Decision Process**:
1. Review synthesized insights
2. Identify what's working
3. Identify what's not working
4. Make decisions (scale, stop, pivot)
5. Plan next experiments
6. Document decisions in Swift CNS

**Example Decisions**:
- Scale: Engineering Managers at 50-200 employee companies, LinkedIn channel, optimized onboarding
- Stop: Email outreach to Directors, Google ads, Feature Z
- Pivot: Test new ICP segment, test new channel, test new feature

**Document in Swift CNS**:
- Create decision framework document
- Document decisions
- Plan next experiments based on decisions

### 6. Close Feedback Loop

**Closing the Feedback Loop**:

**Acknowledge Feedback**:
- Thank users for feedback
- Acknowledge receipt
- Set expectations for response

**Update Users**:
- Let users know when changes are made
- Share improvements based on feedback
- Celebrate wins with users

**Follow Up**:
- Ask for additional feedback
- Check in on improvements
- Continue conversation

**Example Feedback Loop**:
- User feedback: "Onboarding is confusing"
- Response: "Thank you for the feedback. We're working on improving onboarding."
- Update: "We've improved onboarding based on your feedback. Please try it and let us know what you think!"
- Follow-up: "How is the new onboarding working for you?"

**Document in Swift CNS**:
- Create feedback loop system
- Document feedback responses
- Track feedback loop closure

- Creative variant 3 performs best
- Synthesis: LinkedIn ads + blog content + creative variant 3 are winning combination

**Product Synthesis**:
- Onboarding tweak improves first-time success by 30%
- Feature X drives highest engagement
- UX improvement Y reduces friction
- Synthesis: Onboarding optimization + Feature X + UX improvement Y drive product-market fit

**Pattern Recognition**:

# Checklist: Prepare ICP

Use this checklist to verify you've completed the chapter requirements.

## Earlier Research Review
- [ ] Reviewed problem statements from decide section
- [ ] Reviewed assumptions and hypotheses from decide section
- [ ] Reviewed experiment results and learnings from decide section
- [ ] Extracted key insights about users and their needs

## Account-Level ICP
- [ ] Industry is defined (primary industries identified)
- [ ] Company Size is defined (employee range, revenue range)
- [ ] Account characteristics are defined (if relevant)
- [ ] Account-level ICP is documented in Swift CNS

## Role-Level ICP
- [ ] Role is defined (primary role identified)
- [ ] Pains are defined (top 3-5 pains documented)
- [ ] Gains are defined (top 3-5 gains documented)
- [ ] Life Without Solution is defined (current process, tools, workarounds, cost)
- [ ] Role-level ICP is documented in Swift CNS

## Competitor Analysis
- [ ] Direct competitors identified
- [ ] Competitor ICP analyzed
- [ ] Competitor channels analyzed
- [ ] Competitor messaging analyzed
- [ ] Market gaps identified
- [ ] Warm channels identified
- [ ] Competitor analysis documented in Swift CNS

## ICP Hypothesis
- [ ] ICP hypothesis is written (account + role level)
- [ ] Success criteria are defined (metrics + thresholds)
- [ ] Alternative ICPs are identified (if hypothesis fails)
- [ ] ICP hypothesis is documented in Swift CNS

## Validation Plan
- [ ] Explore phase experiment planned
- [ ] Validate phase experiment planned
- [ ] Scale phase experiment planned
- [ ] Decision points defined for each phase
- [ ] Validation plan documented in Swift CNS

## Ready to Proceed
- [ ] All items above are complete
- [ ] ICP framework is comprehensive (account + role level)
- [ ] ICP is documented as testable hypotheses in Swift CNS
- [ ] Competitor analysis is complete
- [ ] Validation plan is ready
- [ ] Ready to proceed to [02 — Develop Messaging Strategy](02-develop-messaging-strategy.md)

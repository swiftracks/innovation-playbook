## Activities

### 1. Build Essential Pages

**Essential Pages for V1**:

**Landing Page** (Homepage):
- **Purpose**: First impression, value communication, conversion
- **Key Elements**:
  - Headline (primary value prop)
  - Subheadline (expanded value prop)
  - Key benefits (3-5 bullets)
  - Social proof (if available)
  - Primary CTA (above fold)
  - Secondary CTA (below fold)
  - Visuals (screenshots, mockups, or illustrations)

**Signup Page**:
- **Purpose**: Convert visitors to users
- **Key Elements**:
  - Clear value reminder
  - Simple signup form (email, password minimum)
  - Trust signals (security, privacy)
  - CTA button
  - Error handling

**Basic Pages**:
- **About**: Who you are, why you exist
- **Features**: Key features aligned with ICP benefits
- **Pricing**: Clear pricing (if applicable for private beta)
- **Contact**: How to reach you

**Page Structure Best Practices**:
- **Above Fold**: Value prop + Primary CTA (visible without scrolling)
- **Mid-Page**: Benefits + Social proof
- **Below Fold**: Secondary CTA + More details
- **Footer**: Links, contact, legal

### 2. Apply Conversion Optimization Principles

**Conversion Optimization Framework**:

**Frame of Mind Alignment**:
- What is ICP thinking when they arrive?
- What stage of awareness are they in?
- What action feels natural at that moment?
- Align messaging and CTAs with frame of mind

**CTA Visual Design**:
- **Size**: Large enough to notice, not overwhelming
- **Color**: Contrasting color (stands out from page)
- **Text**: Clear action verb + benefit
- **Placement**: Above fold, mid-page, below fold
- **Multiple CTAs**: Same page, different contexts

**Visual Hierarchy**:
- **Headline**: Largest, boldest
- **Subheadline**: Medium size
- **Body**: Readable size
- **CTA**: Stands out (color, size)
- **Benefits**: Scannable (bullets, icons)

**Trust Signals**:
- Social proof (testimonials, logos, metrics)
- Security badges
- Privacy statements
- Contact information
- Professional design

**Reduce Friction**:
- Simple signup form (minimal fields)
- Clear value communication
- No unnecessary steps
- Fast loading
- Mobile responsive

**Document in Swift CNS**:
- Create conversion optimization plan
- Document CTA designs
- Plan conversion experiments

### 3. Design CTAs Aligned with Frame of Mind

**CTA Design by Frame of Mind**:

**First Touch (Awareness)**:
- **Frame of Mind**: "What is this? Should I care?"
- **CTA Design**:
  - Low commitment ("See how it works", "Watch demo")
  - Educational ("Learn more", "See examples")
  - Visual: Softer color, smaller size
  - Placement: Mid-page, after value communication

**Consideration (Interest)**:
- **Frame of Mind**: "This looks interesting. Should I try it?"
- **CTA Design**:
  - Medium commitment ("Start free trial", "Get early access")
  - Risk reduction ("No credit card", "Free forever")
  - Visual: Medium color, medium size
  - Placement: Above fold, mid-page

**Decision (Ready)**:
- **Frame of Mind**: "I want this. How do I get started?"
- **CTA Design**:
  - High commitment ("Sign up now", "Get started")
  - Clear action ("Start your first [action]")
  - Visual: Bold color, large size
  - Placement: Above fold, prominent

**CTA Best Practices**:
- **Action Verbs**: Start, Get, Try, See, Learn
- **Specificity**: Not just "Click here"
- **Benefit**: What do they get?
- **Urgency**: When appropriate (limited spots, early access)
- **Risk Reduction**: Free, no credit card, etc.

**Multiple CTAs on Same Page**:
- **Above Fold**: Primary CTA (decision-ready)
- **Mid-Page**: Secondary CTA (consideration)
- **Below Fold**: Tertiary CTA (awareness/reminder)

### 4. Create Website Experimentation Framework

**Website Experimentation**:

**What to Test**:
- **Messaging**: Headlines, subheadlines, value props
- **CTAs**: Text, color, size, placement
- **Layouts**: Page structure, visual hierarchy
- **Visuals**: Images, screenshots, mockups
- **Forms**: Field count, field order, labels

**Experiment Framework**:
- **Explore**: Test multiple variations quickly (days)
- **Validate**: Test winners with ICP (1-2 weeks)
- **Scale**: Scale winning variations (2-4 weeks)

**Example Website Experiments**:

**Explore Phase**:
- Test 3 headline variations (2 days)
- Test 5 CTA variations (2 days)
- Test 2 layout variations (2 days)

**Validate Phase**:
- Test winning headline with target ICP (1 week)
- Test winning CTA with target ICP (1 week)
- Test winning layout with target ICP (1 week)

**Scale Phase**:
- Scale winning variations (2 weeks)
- Optimize based on performance (ongoing)

**A/B Testing Tools**:
- **Simple**: Manual split (different URLs)
- **Advanced**: A/B testing tools (Optimizely, VWO, Google Optimize)
- **Built-in**: Some website builders have A/B testing

**Document in Swift CNS**:
- Create website experiment plans
- Document website hypotheses
- Track website experiments
- Synthesize website insights

### 5. Implement Best Practices for V1 Website

**V1 Website Best Practices**:

**Essential Elements**:
- Clear value proposition (headline + subheadline)
- Key benefits (3-5 bullets)
- Primary CTA (above fold)
- Simple signup form
- Trust signals
- Contact information

**Design Principles**:
- **Clean**: Not cluttered
- **Professional**: Builds trust
- **Fast**: Quick loading
- **Mobile Responsive**: Works on all devices
- **Accessible**: Usable by everyone

**Content Principles**:
- **ICP-Focused**: About them, not you
- **Benefit-Driven**: Focus on benefits, not features
- **Scannable**: Easy to scan (headings, bullets)
- **Clear**: No jargon, clear language

**Technical Requirements**:
- Fast loading (< 3 seconds)
- Mobile responsive
- Secure (HTTPS)
- Analytics tracking
- Error handling

**Don't Over-Engineer**:
- Start simple
- Test and iterate
- Don't need everything perfect
- Focus on conversion

- Create website best practices checklist
- Document website requirements
- Plan website improvements

## Worked Example

**Situation**: Building website V1 for retrospective tool

**Essential Pages**:

  - "50% faster retrospectives"
  - "Actionable insights automatically"

- Secondary CTA (below fold): "See how it works"

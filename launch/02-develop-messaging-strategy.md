# 02 — Develop Messaging Strategy

**Purpose**: Develop messaging framework and formats aligned with ICP

**Outcome**: Have comprehensive messaging strategy with value propositions, CTAs, and channel-specific messaging documented as testable hypotheses in Swift CNS

**Audience**: PM / Dev / Both

**Time**: 3-5 hours

**Prerequisites**: [01 — Prepare ICP](01-prepare-icp.md) - ICP framework complete

## Learning Outcomes

By the end of this chapter, you will be able to:
1. Apply messaging framework: Pains/Gains → Features/Benefits → Messaging
2. Develop value propositions aligned with ICP
3. Design CTAs aligned with audience frame of mind
4. Create channel-specific messaging (LinkedIn, email, website, etc.)
5. Document messaging as testable hypotheses in Swift CNS
6. Plan messaging experimentation approach

## Jobs-to-Be-Done

- **When**: I have a complete ICP framework and need messaging for private beta launch
- **I want**: To develop messaging that resonates with my ICP across all channels
- **So that**: My ICP will understand the value, take action, and engage with the platform

## Inputs

- ICP framework from [01 — Prepare ICP](01-prepare-icp.md)

- Product features and benefits
- Understanding of ICP's frame of mind
- Swift CNS account for documenting messaging hypotheses

## Activities

### 1. Map Pains and Gains to Features and Benefits

**Messaging Framework Foundation**:

**Start with ICP Pains**:
- List top 3-5 pains from ICP framework
- For each pain, identify: What feature solves this? What benefit does it deliver?
- Example: Pain = "Wasted time in retrospectives" → Feature = "AI-powered analysis" → Benefit = "30-minute retrospectives instead of 60"

**Start with ICP Gains**:
- List top 3-5 gains from ICP framework
- For each gain, identify: What feature enables this? What benefit does it deliver?
- Example: Gain = "Actionable insights" → Feature = "AI-generated action items" → Benefit = "Clear next steps for every sprint"

**Create Pains/Gains → Features/Benefits Map**:
```
Pain/Gain → Feature → Benefit

Pain: Wasted time
  → Feature: AI-powered analysis
  → Benefit: 50% faster retrospectives

Gain: Actionable insights
  → Feature: AI-generated action items
  → Benefit: Clear next steps every sprint
```

**Document in Swift CNS**:
- Create messaging framework document
- Map all pains/gains to features/benefits
- Prioritize by ICP importance

### 2. Develop Value Propositions

**Value Proposition Framework**:

**For [ICP Role] who [has this pain], [Product] is a [category] that [key benefit]. Unlike [alternative], we [unique differentiator].**

**Components**:
- **ICP Role**: Who is this for?
- **Pain**: What problem do they have?
- **Category**: What type of solution is this?
- **Key Benefit**: What's the primary benefit?
- **Alternative**: What do they use today?
- **Unique Differentiator**: What makes you different?

**Example Value Propositions**:

**Primary Value Prop**:
"For Engineering Managers who waste time in retrospectives, RetroAI is an AI-powered retrospective tool that delivers actionable insights in 30 minutes. Unlike manual analysis, we automatically identify patterns and generate clear action items."

**Alternative Value Props** (for different channels/contexts):
- "Turn retrospectives into action in 30 minutes"
- "AI-powered retrospectives that actually deliver insights"
- "Stop wasting time. Get actionable insights automatically."

**Test Multiple Variations**:
- Create 3-5 value proposition variations
- Each emphasizes different pain/gain/benefit
- Test in experiments to see what resonates

**Document in Swift CNS**:
- Create value proposition hypotheses
- Document multiple variations
- Plan value prop experiments

### 3. Design CTAs Aligned with Audience Frame of Mind

**CTA Design Principles**:

**Frame of Mind Matters**:
- What is the ICP thinking when they see your CTA?
- What stage of awareness are they in?
- What action feels natural at that moment?

**CTA Framework**:
- **Action Verb**: What do you want them to do?
- **Benefit**: Why should they do it?
- **Urgency/Scarcity**: Why now? (if appropriate)
- **Risk Reduction**: How do you reduce risk?

**CTA Examples by Frame of Mind**:

**First Touch (Awareness)**:
- "See how it works" (low commitment, curiosity)
- "Watch 2-minute demo" (low commitment, educational)
- "Learn more" (low commitment, exploratory)

**Consideration (Interest)**:
- "Start free trial" (medium commitment, try before buy)
- "Get early access" (medium commitment, exclusivity)
- "Join private beta" (medium commitment, community)

**Decision (Ready)**:
- "Start your first retrospective" (high commitment, action-oriented)
- "Get started free" (high commitment, risk reduction)
- "Sign up now" (high commitment, direct)

**CTA Best Practices**:
- Use action verbs (Start, Get, Try, See, Learn)
- Be specific (not just "Click here")
- Align with frame of mind
- Reduce risk (free, no credit card, etc.)
- Create urgency when appropriate (limited spots, early access)

**Document in Swift CNS**:
- Create CTA hypotheses
- Map CTAs to frame of mind
- Plan CTA experiments

### 4. Create Channel-Specific Messaging

**Channel-Specific Considerations**:

**LinkedIn**:
- Professional tone
- Focus on business outcomes
- Use industry language
- Example: "Engineering Managers: Reduce retrospective time by 50% with AI-powered insights"

**Email**:
- Personal tone
- Focus on specific pain
- Direct and clear
- Example: "Stop wasting 2 hours per sprint on retrospectives. Get actionable insights automatically."

**Website Landing Page**:
- Clear value prop
- Multiple CTAs (above fold, mid-page, bottom)
- Social proof
- Example: "Turn retrospectives into action in 30 minutes" + "Start free trial"

**Social Media (Twitter/X)**:
- Concise and punchy
- Focus on one key benefit
- Use hashtags strategically
- Example: "AI-powered retrospectives that actually deliver insights. #Engineering #Agile"

**Content Marketing**:
- Educational tone
- Focus on ICP's challenges
- Soft CTA
- Example: "How Engineering Managers can get actionable insights from retrospectives without manual analysis"

**In-App Messaging**:
- Context-aware
- Focus on immediate value
- Clear next step
- Example: "Complete your first retrospective in 5 minutes"

**Document in Swift CNS**:
- Create channel-specific messaging hypotheses
- Document messaging for each channel
- Plan channel messaging experiments

### 5. Develop Messaging Hierarchy

**Messaging Hierarchy**:

**Level 1: Headline (5-7 words)**
- Primary value prop
- Must grab attention
- Example: "Turn retrospectives into action"

**Level 2: Subheadline (10-15 words)**
- Expand on value prop
- Add key benefit
- Example: "AI-powered retrospectives that deliver actionable insights in 30 minutes"

**Level 3: Key Benefits (3-5 bullets)**
- Top benefits from framework
- ICP-focused
- Example:
  - "50% faster retrospectives"
  - "Actionable insights automatically"
  - "Clear action items every sprint"

**Level 4: Proof Points**
- Social proof
- Metrics/results
- Example: "Used by 100+ Engineering teams"

**Level 5: CTA**
- Aligned with frame of mind
- Clear action
- Example: "Start free trial"

**Use Hierarchy Across Channels**:
- Adapt hierarchy to channel format
- Maintain consistency in value prop
- Vary CTAs by channel context

**Document in Swift CNS**:
- Create messaging hierarchy document
- Document for each channel
- Plan hierarchy experiments

### 6. Plan Messaging Experimentation

**Messaging Experimentation Approach**:

**What to Test**:
- Value proposition variations
- CTA variations
- Channel-specific messaging
- Messaging hierarchy
- Headlines and subheadlines

**Experiment Framework**:
- **Explore**: Test multiple messaging variations quickly (days)
- **Validate**: Test winning variations with ICP (1-2 weeks)
- **Scale**: Scale winning messaging (2-4 weeks)

**Example Messaging Experiments**:

**Explore Phase**:
- Test 3 value prop variations on landing page (2 days)
- Test 5 CTA variations on LinkedIn ads (2 days)
- Test 3 email subject lines (2 days)

**Validate Phase**:
- Test winning value prop with target ICP (1 week)
- Test winning CTA with target ICP (1 week)
- Test channel messaging with target ICP (1 week)

**Scale Phase**:
- Scale winning messaging across channels (2 weeks)
- Optimize based on performance (ongoing)

**Document in Swift CNS**:
- Create messaging experiment plans
- Document messaging hypotheses
- Track messaging experiments
- Synthesize messaging insights

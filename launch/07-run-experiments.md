## Activities

### 1. Understand Three-Phase Experiment Model

**Three-Phase Model Overview**:

**Explore Phase**:
- **Duration**: Days (2-4 days typically)
- **Purpose**: Find ICP signals fast, pivot often
- **Objective**: Find insights that lead to identifying ICP prospects, messages that work, channels to reach them, and key product moments they value
- **Decision Point**: Quick signals indicate promise → move to Validate

**Validate Phase**:
- **Duration**: 1-2 weeks
- **Purpose**: Find ICP patterns from signals
- **Objective**: Validate ICPs with evidence that product delivers value that generates revenue
- **Decision Point**: Strong patterns validate ICP → move to Scale

**Scale Phase**:
- **Duration**: 2-4 weeks
- **Purpose**: Scale ICP engagement
- **Objective**: Scale engagement with validated ICPs to drive business value insights that inform strategy
- **Decision Point**: Scaling successfully → continue and optimize

**Time Boundaries**:
- Experiments have clear time boundaries aligned with phases
- Don't run experiments indefinitely
- Make decisions at phase boundaries
- Pivot or scale based on signals

**Document in Swift CNS**:
- Create experiment framework document
- Document three-phase model
- Plan experiments by phase

### 2. Run Outbound Experiments

**Outbound Experiment Categories**:

**Sales Experiments**:

**Explore Phase (Days)**:
- **Example**: "One Role, Two Sub-verticals"
  - Call same role across two sub-verticals within same industry
  - Goal: See if one sub-vertical has higher conversion to discovery calls
  - Decision Point: After Week 1 (15-20 quality dials), if one sub-vertical shows clear proof, focus on it
  - Principles: Find Who Owns the Problem, Adopt the Buyer's Language, Small Sample Strong Switch

**Validate Phase (1-2 weeks)**:
- **Example**: "Two Reps, One ICP/Value Prop, Test Channel + Entry Persona"
  - Reps run different channel/persona combinations over two weeks
  - Goal: 10 real conversations
  - Decision Point: After 10 real conversations, if one path shows clear stage progression, focus on that path
  - Principles: Same Bet Multiple Pathways, Rep Experiments Not Opinions, Measure Progress Not Dials

**Scale Phase (2-4 weeks)**:
- Scale winning channel/persona combination
- Optimize messaging and process
- Drive repeatable acquisition

**Outbound Experiment Framework**:
- Test ICP segments
- Test messaging variations
- Test channels (email, LinkedIn, phone)
- Test entry personas
- Test value propositions

- Create outbound experiment plans

### 3. Run Growth Marketing Experiments

**Growth Marketing Experiment Categories**:

**Paid Advertising Experiments**:

**Explore Phase (Days)**:
- **Example**: "Tiny Paid + Single Action Page (2-4 days)"
  - Small spend to two audiences, same message, one simple CTA
  - Goal: See if ICP responds
  - Decision Point: If one audience responds meaningfully more, shift spend and probe that segment
  - Principles: Deliver a First Outcome, Reversible by Design, Decide on the Earliest Signal

**Validate Phase (1-2 weeks)**:
- **Example**: "Parallel Creative Set Test (LinkedIn example) (7-10 days)"
  - Run 3-5 creative variants to same ICP, placements, and post-click path
  - Split budget evenly
  - Goal: See which creative set drives most engagement
  - Decision Point: End of week 1, if promoted variant still wins, back as default and scale, reserving 10-20% for challengers
  - Principles: Parallel Within Guardrails, Fair Tests Clear Promotes, Budget Follows Learning

**Scale Phase (2-4 weeks)**:
- Scale winning creative set
- Optimize budget allocation
- Drive repeatable acquisition

**Organic Content Experiments**:

**Explore Phase (Days)**:
- Test content types (blog, social, video)
- Test topics (ICP pain points)
- Test channels (LinkedIn, Twitter, communities)
- Quick signals indicate what resonates

**Validate Phase (1-2 weeks)**:

**Scale Phase (2-4 weeks)**:

### 4. Run Product Experiments

**Product Experiment Categories**:

**Feature Experiments**:

**Explore Phase (Days)**:
- **Example**: "Onboarding Toggle (24-48h)"
  - Add one reversible tweak to very first step (e.g., default template, CTA order, helper text)
  - Expose to small percent of new users
  - Decision Point: If tweak clearly helps or harms first-time success, keep or roll back immediately
  - Principles: Deliver a First Outcome, Reversible by Design, Decide on the Earliest Signal

**Validate Phase (1-2 weeks)**:
- **Example**: "Pick 3 Friction Points, Build 2 Small Tests Each"
  - Pick 3 friction points on first-time path
  - Build 2 small tests (overlaid) behind flags for each
  - Roll to 10-20% of new users in parallel
  - Goal: See if any test improves first-time outcome completion by threshold without raising support/latency
  - Decision Point: If one test clearly helps, promote it immediately and pause the 'next' test for that friction point
  - Principles: Add Without Breaking, Prove on the Critical Path, Promote What Wins

**Scale Phase (2-4 weeks)**:
- Scale winning features
- Optimize feature performance
- Drive product-market fit

**UX Experiments**:

**Explore Phase (Days)**:
- Test UX variations (layouts, flows, interactions)
- Quick signals indicate UX effectiveness

**Validate Phase (1-2 weeks)**:
- Test winning UX variations with ICP
- Validate UX effectiveness
- Measure engagement and completion

**Scale Phase (2-4 weeks)**:

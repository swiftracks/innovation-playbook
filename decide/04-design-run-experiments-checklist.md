# Checklist: Design & Run Experiments

Use this checklist to verify you've completed the chapter requirements.

## Experiment Design
- [ ] Experiment is designed with clear method
- [ ] Experiment type is appropriate for hypothesis
- [ ] Success criteria are defined

## Experiment Setup
- [ ] Experiment is set up (tools, tracking, etc.)
- [ ] Experiment is tested before launch
- [ ] Tracking and analytics are configured

## Experiment Execution
- [ ] Experiment is launched to users
- [ ] Traffic is driven (if needed)
- [ ] Experiment is monitored for issues

## Data Collection
- [ ] Data collection is in place
- [ ] Sample size is sufficient (meet success criteria)
- [ ] Quantitative data is collected
- [ ] Qualitative data is collected (if applicable)

## Results Documentation
- [ ] Results are documented
- [ ] Initial observations are noted
- [ ] Ready to proceed to [05 — Extract Key Learnings](05-extract-key-learnings.md)

## Ready to Proceed
- [ ] All items above are complete
- [ ] At least one experiment is complete
- [ ] You have reliable data (met sample size)
- [ ] Ready to proceed to [05 — Extract Key Learnings](05-extract-key-learnings.md)

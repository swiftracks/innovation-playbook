# Checklist: Form Testable Hypotheses

Use this checklist to verify you've completed the chapter requirements.

## Hypothesis Format
- [ ] All critical assumptions are converted to hypotheses
- [ ] Hypotheses use the correct format: "We believe... If... Then... We'll know..."
- [ ] Success criteria are defined for each hypothesis

## Hypothesis Canvas
- [ ] Hypothesis canvases are created for top 3-5 hypotheses
- [ ] Each canvas includes: hypothesis, assumption, category, priority, success criteria, test method

## Prioritization
- [ ] Hypotheses are prioritized by risk, impact, and testability
- [ ] Top priority hypotheses are identified

## Success Criteria
- [ ] Metric is defined for each hypothesis
- [ ] Threshold is defined for each hypothesis
- [ ] Timeline is defined for each hypothesis
- [ ] Sample size is defined for each hypothesis

## Documentation
- [ ] Hypotheses are documented
- [ ] Hypothesis canvases are documented
- [ ] Prioritization is documented
- [ ] Ready to proceed to [04 — Design & Run Experiments](04-design-run-experiments.md)

## Ready to Proceed
- [ ] All items above are complete
- [ ] Top 3-5 hypotheses are ready for testing
- [ ] Ready to proceed to [04 — Design & Run Experiments](04-design-run-experiments.md)

# Testable Hypotheses Template

Use this template to convert critical assumptions into testable hypotheses.

## Hypothesis Format

Use this format for each hypothesis:

```
We believe [assumption].
If [condition],
Then [outcome].
We'll know this is true when [metric].
```

## Hypothesis Canvas

For each hypothesis, complete:

```
Hypothesis: [Full hypothesis statement]
Assumption: [Underlying assumption]
Category: [User/Technical/Business/Value]
Priority: [High/Medium/Low]
Success Criteria:
  - Metric: [What to measure]
  - Threshold: [Success threshold]
  - Timeline: [When to measure]
  - Sample Size: [How many needed]
Test Method: [How you'll test it]
```

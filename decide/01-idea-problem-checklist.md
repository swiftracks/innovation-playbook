# Checklist: Idea / Problem

Use this checklist to verify you've completed the chapter requirements.

## Problem Statement
- [ ] Problem is clear and specific
- [ ] Target users are identified
- [ ] Context is defined
- [ ] Impact is articulated

## Jobs-to-Be-Done
- [ ] At least 2-3 Jobs-to-Be-Done documented
- [ ] Each uses the format: When / I want / So that
- [ ] Jobs-to-Be-Done represent real user needs

## Value Proposition
- [ ] Value proposition is articulated
- [ ] Includes target users
- [ ] Includes key benefit
- [ ] Includes unique differentiator

## User Validation
- [ ] Conducted 3-5 user interviews
- [ ] Asked about current approach
- [ ] Asked about pain points
- [ ] Asked about frequency
- [ ] Asked about willingness to pay

## Problem Worthiness Assessment
- [ ] Frequency assessed
- [ ] Severity assessed
- [ ] Urgency assessed
- [ ] Willingness to pay assessed
- [ ] Problem is worth solving (all criteria met)

## Documentation
- [ ] Problem statement is documented
- [ ] Jobs-to-Be-Done are documented
- [ ] Value proposition is documented
- [ ] User interview notes are documented
- [ ] Problem worthiness assessment is documented

## Ready to Proceed
- [ ] All items above are complete
- [ ] Problem is validated through user research
- [ ] Problem is worth solving
- [ ] Ready to proceed to [02 — Identify Critical Assumptions](02-identify-critical-assumptions)

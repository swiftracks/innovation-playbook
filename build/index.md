# Build the MVP

> **Purpose**: Build a working MVP efficiently with minimal resources
> **Outcome**: Have a working MVP that demonstrates value and enables learning
> **Audience**: PM / Dev / Both
> **Time**: 2-4 weeks (depending on complexity)
> **Prerequisites**: [Decide What to Build](decide/index.md) - Decision to build

## Learning Outcomes

By the end of this section, you will be able to:
1. Set up development environment and infrastructure
2. Build an AI baseline for core functionality
3. Create a thin vertical UX that demonstrates end-to-end value
4. Implement quality and observability essentials
5. Deploy a working MVP ready for testing

## Jobs-to-Be-Done

- **When**: I have a validated idea and decision to build
- **I want**: To build a working MVP efficiently
- **So that**: I can test with real users and learn quickly

## Inputs

- Decision to build from [06 — Synthesize Insights → Decision](decide/06-synthesize-insights-decision.md)
- Validated hypotheses and learnings
- Problem statement and value proposition
- Understanding of user needs

## Activities

This section follows a systematic build process:

1. **[05 — Setup](05-setup.md)**: Set up development environment and infrastructure
2. **[06 — AI Baseline](06-ai-baseline.md)**: Build core AI functionality
3. **[07 — UX Thin Vertical](07-ux-thin-vertical.md)**: Create a complete user journey
4. **[08 — Quality & Observability (Lite)](08-quality-observability-lite.md)**: Implement essentials for quality and monitoring

> 💡 **Tip**: Setup must come first. AI Baseline and UX Thin Vertical can be done in parallel after setup.

## Worked Example

**Situation**: Building MVP for retrospective tool

**Process**:
1. **Setup**: Development environment, CI/CD, deployment infrastructure
2. **AI Baseline**: Basic AI model for generating retrospective insights
3. **Thin Vertical**: Complete user journey from signup → create retrospective → view insights
4. **Quality & Observability**: Error tracking, basic analytics, logging
5. **Deploy**: MVP deployed and ready for private beta

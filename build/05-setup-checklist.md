# Checklist: Setup

Use this checklist to verify you've completed the chapter requirements.

## Phase 1: Planning

### User Stories
- [ ] User stories generated using AI tools (ChatGPT, Claude, or Cursor)
- [ ] User stories reviewed and iterated on
- [ ] User stories finalized and prioritized
- [ ] User stories align with MVP scope

### Product Requirements Document (PRD)
- [ ] PRD generated using AI tools
- [ ] PRD reviewed and refined
- [ ] All PRD sections completed (Purpose, Scope, Personas, User Journeys, Requirements, etc.)
- [ ] PRD includes acceptance criteria for each feature
- [ ] PRD finalized and ready for implementation

### UX Mockups
- [ ] User flows created in UX Pilot
- [ ] Screens generated for all key user journeys
- [ ] Mockups iterated on and refined
- [ ] All screens referenced in PRD are created
- [ ] All mockups exported to PNG format

## Phase 2: Setup & Execution

### Git Repository
- [ ] GitLab or GitHub repository created
- [ ] Repository cloned in Cursor
- [ ] Repository URL documented

### Cursor Configuration
- [ ] `.cursorrules` file created in project root
- [ ] `.cursorrules` customized with project-specific rules
- [ ] Rules include TypeScript, React, and MVP-specific guidelines
- [ ] Rules cover code quality standards

### Cursor Plan Mode
- [ ] PRD document provided to Cursor
- [ ] All mockup PNG files uploaded to Cursor
- [ ] Foundation tech stack specified
- [ ] Implementation plan generated by Cursor
- [ ] Implementation plan reviewed
- [ ] Implementation plan approved (or adjusted if needed)

### Development Environment
- [ ] Project structure created following the plan
- [ ] Initial dependencies installed
- [ ] Development environment tested
- [ ] Ready to begin building

## Documentation

- [ ] User stories list documented
- [ ] PRD document saved
- [ ] Mockup files organized and accessible
- [ ] `.cursorrules` file committed to repository
- [ ] Implementation plan documented
- [ ] Setup process documented (if needed)

## Ready to Proceed

- [ ] All Planning Phase items complete
- [ ] All Setup & Execution Phase items complete
- [ ] Implementation plan approved
- [ ] Ready to proceed to [06 — AI Baseline](06-ai-baseline.md) or [07 — UX Thin Vertical](07-ux-thin-vertical.md)

**Next Step**: Proceed to [06 — AI Baseline](06-ai-baseline.md) or [07 — UX Thin Vertical](07-ux-thin-vertical.md) when all items are checked.

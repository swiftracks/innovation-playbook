# 07 — UX Thin Vertical

**Purpose**: Build a complete user journey that demonstrates end-to-end value

**Outcome**: Have a working thin vertical that users can complete successfully

**Audience**: PM / Dev / Both

**Time**: 1-2 weeks

**Prerequisites**: [05 — Setup](05-setup.md)

## Learning Outcomes

By the end of this chapter, you will be able to:
1. Design a thin vertical user journey
2. Build a complete end-to-end user experience
3. Implement core UX flows that demonstrate value
4. Create a polished, functional interface
5. Test user journey with real users

## Jobs-to-Be-Done

- **When**: I have development environment set up and need to build user experience
- **I want**: To build a complete user journey that demonstrates value
- **So that**: Users can experience the full value proposition

## Inputs

- Development environment from [05 — Setup](05-setup.md)
- Understanding of user needs from validated hypotheses
- Design mockups or wireframes (if available)
- Value proposition and user journey

## Activities

### 1. Design Thin Vertical

**Define User Journey**:
- What is the complete user journey?
- What steps are essential?
- What can be simplified or removed?

**Thin Vertical Principles**:
- **Narrow**: Focus on one complete journey
- **Deep**: Complete end-to-end value
- **Polished**: Works well, not perfect

**Example** (Retrospective Tool):
- Signup → Create retrospective → Add feedback → View insights → Export

> 💡 **Tip**: Choose the most important user journey. Don't build everything.

### 2. Build Core UX Flows

**Essential Flows**:
- **Onboarding**: Signup/login
- **Core Value**: Main user journey
- **Success**: Completion and value delivery

**Implementation**:
- Build flows step by step
- Focus on functionality over polish
- Ensure flows work end-to-end
- Test each flow

### 3. Create User Interface

**UI Principles**:
- **Simple**: Clean, uncluttered
- **Functional**: Works well
- **Polished**: Looks professional
- **Accessible**: Usable by all

**Tools**:
- **Framework**: React, Vue, or similar
- **Styling**: Tailwind, Bootstrap, or similar
- **Components**: Build or use library

> 📝 **Note**: Don't over-design. Focus on functionality first.

### 4. Integrate with Backend

**Connect Frontend to Backend**:
- API integration
- Data fetching
- State management
- Error handling

**Example**:
- Frontend: React components
- Backend: Express API
- Integration: API calls, state management

### 5. Test User Journey

**Testing**:
- Test complete user journey
- Verify flows work end-to-end
- Test error cases
- Get user feedback

**User Testing**:
- Test with real users
- Observe completion rate
- Gather feedback
- Identify issues

## Worked Example

**Situation**: Building thin vertical for retrospective tool

**Thin Vertical Journey**:
1. **Signup**: User creates account
2. **Create Retrospective**: User creates new retrospective
3. **Add Feedback**: User adds feedback items
4. **Generate Insights**: AI generates insights
5. **View Insights**: User views AI-generated insights
6. **Export**: User exports insights

**Implementation**:
- Frontend: React + TypeScript
- Backend: Node.js + Express
- Integration: API calls for all flows
- Testing: Test with 5-10 users

**Results**:
- 8 out of 10 users completed journey
- Average time: 5 minutes
- Feedback: "Easy to use", "Insights are helpful"
- Issues: Export button needs improvement

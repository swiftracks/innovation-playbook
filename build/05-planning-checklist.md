# Checklist: Planning

Use this checklist to verify you've completed the planning phase requirements. For detailed guidance on each activity, see the respective sub-pages.

## User Stories

See detailed guide: [05 — Planning: User Stories](05-planning-user-stories.md)

- [ ] User stories generated using AI tools (ChatGPT, Claude, or Cursor)
- [ ] User stories reviewed and iterated on
- [ ] User stories finalized and prioritized (Must Have / Should Have / Could Have)
- [ ] User stories align with MVP scope
- [ ] All core functionality covered in user stories

## Product Requirements Document (PRD) & AI Baseline

See detailed guide: [05 — Planning: PRD & AI Baseline](05-planning-prd.md)

- [ ] PRD generated using AI tools
- [ ] PRD reviewed and refined
- [ ] All PRD sections completed (Purpose, Scope, Personas, User Journeys, Requirements, etc.)
- [ ] PRD includes acceptance criteria for each feature
- [ ] PRD finalized and ready for implementation
- [ ] AI Baseline planned and designed (if applicable)
- [ ] AI service and model selected (if applicable)
- [ ] Prompt templates designed (if applicable)
- [ ] AI features documented in PRD (if applicable)

## UX Mockups

See detailed guide: [05 — Planning: Mockups](05-planning-mockups.md)

- [ ] User flows created in UX Pilot
- [ ] Screens generated for all key user journeys
- [ ] Mockups iterated on and refined
- [ ] All screens referenced in PRD are created
- [ ] Complete user journey designed
- [ ] Error states designed
- [ ] Empty states designed
- [ ] All mockups exported to PNG format
- [ ] PNG files organized and accessible

## Documentation

- [ ] User stories list documented
- [ ] PRD document saved
- [ ] Mockup files organized and accessible
- [ ] AI Baseline plan documented (if applicable)
- [ ] Planning artifacts ready for Setup phase

## Ready to Proceed

- [ ] All items above are complete
- [ ] User stories finalized and prioritized
- [ ] PRD complete and reviewed
- [ ] All mockups created and exported
- [ ] AI Baseline planning complete (if applicable)
- [ ] Ready to proceed to [06 — Setup](06-setup.md)

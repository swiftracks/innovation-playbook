# Rapid Triage for Contradictory Signals

## Context

Two experiments on the same hypothesis produced mixed signals in one sprint.

## Recommendation

Classify each signal by reliability before changing direction.
Run one narrow follow-up test focused on the highest-impact uncertainty.

## Evidence and Rationale

- Signal A meets pre-declared criteria but has low sample size.
- Signal B misses criteria but has better cohort quality.
- Confidence should decrease in broad rollout assumptions until targeted retest completes.

## Decision Next Action

Iterate, not pivot.
Design a short retest with explicit invalidation criteria and run within current cycle window.

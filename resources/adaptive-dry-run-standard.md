# Standard Stage Method — Evidence Readiness Before Learning Lock

## Purpose

Ensure evidence is strong enough before a team promotes observations into formal learning statements.

## Outcome

A learning candidate set with confidence labels and explicit unresolved uncertainty.

## Inputs

- Completed experiment record
- Captured artifacts (metrics, notes, transcripts)
- Pre-declared success and invalidation criteria

## Steps in SwiftCNS

1. Map each key observation to a criterion.
2. Tag each observation as strong, partial, or weak signal.
3. Isolate confounders and note impact on interpretation.
4. Draft a confidence-change statement tied to strongest signals.
5. Define one follow-up question if confidence is still ambiguous.

## Quality Gates

- Every major claim is linked to at least one concrete artifact.
- Confidence language is proportional to signal quality.
- Contradictions are disclosed, not hidden.

## Outputs

- Evidence triage note
- Candidate learning statement
- Follow-up uncertainty list

## Definition of Done

- Team can state what changed in confidence.
- Team can state what still remains unknown.
- Output can support go/iterate/pivot/stop discussion.

## Next Step

Move to learning extraction only after quality gates pass.
